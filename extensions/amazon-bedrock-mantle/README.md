# Urbicana Amazon Bedrock Mantle Provider

Official Urbicana provider plugin for routing Amazon Bedrock Mantle models through OpenAI-compatible provider flows.

Install from Urbicana:

```bash
openclaw plugins install @openclaw/amazon-bedrock-mantle-provider
```

Use this plugin when your Bedrock deployment exposes Mantle-compatible model routing and you want Urbicana agents to address those models through the Bedrock Mantle provider.
